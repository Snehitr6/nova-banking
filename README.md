# 🏦 NovaBank — Banking Dashboard

A modern, responsive **Banking Dashboard UI** built with **React.js, Vite, and Tailwind CSS**. The application provides a professional banking experience with account management, transactions, payments, cards, financial analytics, settings, dark mode, responsive navigation, and smooth page transitions.

## ✨ Features

* 🏠 **Dashboard**

  * Total balance overview
  * Income and expense statistics
  * Recent transactions
  * Spending overview
  * Quick transfer
  * Quick payment options

* 💳 **Accounts**

  * Account balance
  * Account information
  * Account activity
  * Financial overview

* 💸 **Transactions**

  * Search transactions
  * Filter by income and expenses
  * Date filtering
  * Advanced filters
  * Transaction details
  * CSV export

* 💳 **Cards**

  * Digital bank card interface
  * Show/hide card number
  * Show/hide CVV
  * Copy card number
  * Freeze/unfreeze card
  * Card management

* 💰 **Payments**

  * UPI payments
  * Bill payments
  * Mobile recharge
  * Scan & Pay
  * Saved recipients
  * Payment confirmation
  * Recent payments

* 📊 **Analytics**

  * Financial insights
  * Spending overview
  * Savings information
  * Analytics preview

* ⚙️ **Settings**

  * Edit profile
  * Change password
  * Biometric authentication
  * Notification preferences
  * Language selection
  * Currency selection
  * Date format
  * Balance privacy
  * Light/Dark mode
  * Device management
  * Logout
